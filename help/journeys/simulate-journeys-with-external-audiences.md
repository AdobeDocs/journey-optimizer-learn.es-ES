# Simular recorridos con público externo

Obtenga información sobre cómo simular recorridos que utilizan perfiles de público externo de un archivo CSV o una composición de público federado, incluidos atributos no almacenados en el perfil, como el ID de ticket o la fecha de viaje. En este vídeo se explica cómo filtrar un público, personalizar mensajes con atributos externos, crear un usuario simulado y simular de los datos de público para validar la ruta correcta antes de que el recorrido se active.
